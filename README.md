# World Population Exploratory Data Analysis

## Project Overview
This project explores global population data using Python to identify population trends, examine relationships between variables and compare population statistics across continents.

## Analysis Performed
- Explored the dataset structure and summary statistics.
- Examined missing values and unique records.
- Identified the 10 most populated countries based on 2022 population.
- Analyzed correlations between numerical variables.
- Compared average population statistics across continents.
- Visualized population trends across continents from 1970 to 2022.
- Used boxplots to identify potential outliers.

## Tools and Libraries
- Python
- Pandas
- Matplotlib
- Seaborn
- Google Colab / Jupyter Notebook

## Project File
- world_population_EDA.ipynb
- world_population.csv 

## Objective
To develop insights into global population patterns through exploratory data analysis and data visualization.
